How to play the gallery.

Menus differ by brand. The idea is the same: put the folder on a stick or in a media app, open Photos, start Slideshow.

Samsung

Insert the USB. Open Art, Photo, or the USB source from Home. Choose the Family Gallery folder. Start Slideshow. Set interval to 20–45 seconds if the set allows it.

LG

Insert the USB. Open Photo & Video. Select the folder. Press Slideshow. In settings, pick interval and shuffle if offered.

Roku

Use a Roku with USB, or copy the folder to a computer and play through the Roku Media Player / a connected drive. Open the folder and start a photo slideshow.

Fire TV / Google TV

Use a USB-C hub if the stick needs one. Open a photo or file app (Files, VLC, or the built-in gallery). Browse to the folder and start slideshow.

Apple TV

Copy the folder into Photos on a Mac and use AirPlay, or add the folder to a NAS / Infuse / VLC and play from there. Apple TV has no simple USB port.

Laptop to HDMI

Open the folder, start the computer’s photo slideshow, and send the picture to the television. Works when the set is stubborn.
