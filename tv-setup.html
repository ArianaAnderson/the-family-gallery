Setup guide

Set up your USB art slideshow.

Menus differ, but the basic process is similar on most televisions that support USB photo playback.

Quick start

  1. Plug the USB directly into a USB port on the television—not into a soundbar.
  2. Using the remote, open Photos, USB, Media Player, Gallery, Inputs, or Connected Devices.
  3. Open a picture and select Slideshow or Play.
  4. Turn Repeat or Loop on.
  5. Set the image interval to approximately 45–90 seconds.

Common menu paths

The names below are general starting points; exact steps vary by model and software version.

  • Samsung: Home → Source or Connected Devices → USB → Photos
  • LG: Home → Photo & Video or Inputs → USB → Photos
  • Sony: Apps → Gallery or Files → USB
  • Roku TV: Home → USB or Media Player → Photos
  • Hisense, TCL, or Vizio: Input → USB → Photo

If the TV shows nothing

  • Try the other USB port.
  • Plug the drive directly into the TV; avoid hubs and extension cables.
  • Confirm the selected input or media source is the USB drive.
  • Restart the TV with the USB inserted.
  • Check the television manual for supported USB storage and JPEG photo playback.
Do not reformat the USB casually. Reformatting erases its contents. Email help@familygallerytv.com before making changes if you need assistance.

Display tips

Start with a 45–90 second interval, enable repeat, reduce unnecessary screen enhancement if colors look unnatural, and follow the manufacturer’s screen-care advice.

For a more thoughtful viewing experience, leave enough time to read the artwork title and artist before the next image appears. Invite your family to choose a favorite and talk about what caught their eye, or note an artist to explore later.
